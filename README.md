# 4D航迹预测及可视化系统（原型）

本仓库提供一个可运行的网页原型，用于展示“融合在线更新 GRU 的 4D 航迹预测与可视化系统”的核心设计思路与交互流程，覆盖：

- 单步 / 多步短期预测场景
- 4D 目标输出（经度、纬度、高度、过点时间）
- 在线更新策略与误差抑制机制
- 实时监控、历史回溯、趋势分析可视化

## 快速启动

```bash
python3 serve.py
```

启动后访问：

- http://localhost:8000

## 页面结构

1. **研究与系统目标**：对应空管业务需求与场景价值。
2. **数据预处理流程**：插值、特征扩展、截断、异常点处理。
3. **预测模型配置**：切换单步/多步模式并查看样例输出。
4. **在线更新 GRU 流程**：展示“观测 → 预测 → 校正 → 更新”闭环。
5. **可视化地图与图表**：实时航迹、历史航迹、趋势曲线联动。

## 说明

当前为原型系统：

- 前端使用 `HTML + CSS + JavaScript`。
- 地图使用 Leaflet（CDN）进行航迹点和折线展示。
- 图表使用 ECharts（CDN）展示高度与速度趋势。
- 预测结果为可复现的仿真示例，便于后续替换为真实在线模型推理接口。
